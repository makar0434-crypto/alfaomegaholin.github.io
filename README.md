# AlfaOmega — многостраничный сайт

Статический адаптивный сайт на HTML/CSS/JavaScript без сборки и зависимостей.

## Страницы
- `index.html` — главная
- `about.html` — о проекте и основателе Макаре
- `cooperation.html` — форматы сотрудничества
- `partners.html` — раздел партнёрских программ
- `cases.html` — кейс участника
- `faq.html` — FAQ с поиском и раскрывающимися ответами
- `contact.html` — контакты и форма-запрос, которая открывает Telegram

## Локальный просмотр
Откройте `index.html` в браузере. Для локального сервера можно выполнить в этой папке:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

## Публикация
1. Загрузите все файлы и папку проекта в GitHub.
2. На Netlify выберите Add new site → Import an existing project и подключите репозиторий; команда сборки не нужна, папка публикации — корень проекта.
3. Либо загрузите содержимое папки через Netlify Drop / любой статический хостинг.
4. Подключите собственный домен в настройках хостинга при необходимости.

## Что проверить перед публикацией
- Подтвердите актуальность и разрешение на упоминание банков и их товарных знаков. В `partners.html` названия Альфа-Банка, ВТБ и Т-Банка обозначены как направления, а не как подтверждение официального партнёрства.
- Получите разрешения на публикацию отзывов, изображений и кейсов; текущий кейс сокращён и не содержит скриншотов.
- Проверьте юридические условия партнёрских программ, формулировки о выплатах и требования к возрасту.
- Укажите необходимые документы сайта (политика конфиденциальности и согласие на обработку данных), если добавите серверную форму или начнёте собирать данные.
- Форма сейчас ничего не отправляет на сервер: она подготавливает текст и открывает `https://t.me/holinmoder`.

## Брендинг и анимация
Логотип AΩ — временный текстовый знак. Переходы между внутренними страницами анимируются лаймовым экраном с AΩ. Замените текстовый знак на официальный логотип, если он у вас есть.

## Анимированные вращающиеся элементы
На главной добавлены вращающиеся орбиты вокруг знака AΩ на CSS — они не требуют отдельного GIF-файла, быстро загружаются и учитывают настройку reduced motion. Это стилизованная CSS-анимация. При необходимости её можно заменить на оригинальные GIF-файлы или фирменную анимацию.


### Интерактивный фон
На компьютерах мягкое лаймовое свечение следует за курсором. На телефонах эффект отключён, чтобы не мешать прокрутке и не расходовать лишние ресурсы.


### Интерактивные эффекты
На компьютерах при наведении на логотипы и декоративные значки они слегка наклоняются вслед за положением курсора. Эффект отключается на сенсорных устройствах и при включённом системном уменьшении анимации.
